## Overview of the Project
NFC Luggage Tag will be designed in this project and I will be sharing my progress on the completion. <br>
This project involves in designing, manufacturing, and assembling self-designed PCB.

Goals:<br>

* PCB design
* ECAD software: Altium and KiCAD
* Schematic Layout Design
* PCB Layout Design
* PCB Manufacturing
* Soldering
* Verification and Debugging

## ECAD Software

Altium or KiCAD is recommended in this project. However, I'll be demonstrating both of these software designs.

### ALTIUM Designer 
Altium is expected to be the easiest to follow along. Provided resources is expected to be be natively supported in Altium Designer.

### KiCAD

Open sourse software. KiCAD can import Altium files.

Differences: Each project opens in a new window instead of nested under each project on the left menu.
